# Monthly Cost Report Guide

*Synthetic example document, invented for this repository's evaluation. It describes no real organisation.*

## 1. Timing

The cost report covers the previous calendar month and the cut-off is the last day of that month. It is issued by the 5th working day of the following month. If it is more than 2 working days late, the Programme Controls Manager is told.

## 2. Columns

Each work package shows the approved budget, the committed amount, the actual spend, the forecast at completion and the variance. Actual spend means invoices that are paid or accrued. Figures are reported in thousands of dollars and rounded to the nearest thousand.

## 3. Accruals

Work that was delivered but not yet invoiced at the cut-off is accrued if its value is above $5,000. Smaller amounts are left for the month in which the invoice arrives.

## 4. Variance thresholds

A work package is amber when its forecast at completion is more than 5 percent over its approved budget and red when it is more than 10 percent over. Every amber or red work package needs a short recovery note that says what will bring the forecast back.

## 5. Earned value

The cost performance index is earned value divided by actual cost. A cost performance index below 0.9 triggers a review of the work package by the cost controller. The schedule performance index is earned value divided by planned value and is reviewed in the same way when it falls below 0.9.

## 6. Contingency

Cost contingency is held centrally at 10 percent of the base estimate and is not spread across work packages. It can be drawn only against an approved change request. Each drawdown appears as its own line in the report with the CR number beside it.

## 7. Forecasts and sign-off

The cost controller reviews every forecast and the Project Manager signs it. A forecast is rebuilt from the latest committed amounts each month and is never rolled forward unchanged from the month before.

## 8. Reconciliation

The report is reconciled with the finance ledger each month. A difference of more than 1 percent between the two must be investigated before the report is issued.
